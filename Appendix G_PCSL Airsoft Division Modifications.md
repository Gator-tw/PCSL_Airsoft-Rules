# Appendix G_PCSL Airsoft Division Modifications

This appendix outlines the specific equipment, capacity, and divisional requirements for Airsoft platforms, modifying or superseding the standard firearm divisions detailed in [Appendix A_Pistol Divisions](Appendix%20A_Pistol%20Divisions.md) and [Appendix B_Rifle Divisions](Appendix%20B_Rifle%20Divisions.md).

## G.1 Pistol Divisions Modifications

The following rules apply to all Airsoft handguns and Pistol Caliber Carbines (PCC) used in PCSL matches, modifying their respective sections in [Appendix A_Pistol Divisions](Appendix%20A_Pistol%20Divisions.md). Criteria regarding Minimum Caliber, Maximum Caliber, Maximum Bullet Velocity, and Minimum Power Factor are completely removed and superseded by the kinetic energy limits defined in [Section F.4.1](<Appendix F_PCSL Airsoft Modifications.md#id-f.4.1-chronograph-and-kinetic-energy-limits>).

### G.1.1 Competition (COMP)

Modifying [Section A.1.1](<Appendix A_Pistol Divisions.md#a.1.1-competition-comp>):

| **Criteria** | **Specification** |
| --- | --- |
| **Maximum rounds loaded in magazines at start signal** | 30 |
| **Maximum magazine length** | no |
| **Handgun requirement** | Must be a handgun per [Section 2.4.1](<02_Competitor Equipment.md#id-2.4.1-handgun>) |
| **Other restrictions** | no |

### G.1.2 Practical (PRAC)

Modifying [Section A.1.2](<Appendix A_Pistol Divisions.md#a.1.2-practical-prac>):

| **Criteria** | **Specification** |
| --- | --- |
| **Maximum rounds loaded in magazines at start signal** | 20 |
| **Maximum magazine length** | no |
| **Compensators and Barrel Porting** | Allowed (due to lack of actual recoil mitigation in Airsoft platforms) |
| **Slide Material** | Must be metal |
| **Split-Slide Design** | Allowed (e.g., sight block style), provided the separation point is not behind the halfway point of the barrel |
| **Slide Lightening Cuts** | Lightening cuts are not allowed behind the ejection port |
| **Frame mounted optics** | no |
| **Gas Pedals** | no restrictions |
| **Flashlights/lasers** | allowed |
| **Magwells** | allowed |
| **Handgun requirement** | Must be a handgun per [Section 2.4.1](<02_Competitor Equipment.md#id-2.4.1-handgun>) |
| **Other restrictions** | no |

### G.1.3 Pistol Caliber Carbine (PCC)

Modifying [Section A.1.3](<Appendix A_Pistol Divisions.md#a.1.3-pistol-caliber-carbine-pcc>):

| Criteria | Specification |
| --- | --- |
| **Coupled magazines** | Coupled (side-by-side) magazines are prohibited |
| **Short-Stroke Kits** | Any rifle platform equipped with a short-stroke kit or similar internal bolt-travel restriction modification is strictly classified as a PCC, regardless of its original external appearance or real-steel caliber counterpart. |
| **Support devices** | Tripods, bipods, bags, and related support devices are prohibited |
| **Rifle requirement** | Must be a rifle per [Section 2.4.2](<02_Competitor Equipment.md#id-2.4.2-rifle>) |
| **Other restrictions** | no |

### G.1.4 Defensive Practical (DP)

Modifying [Section A.1.4](<Appendix A_Pistol Divisions.md#a.1.4-defensive-practical-dp>):

| **Criteria** | **If non-ported/non-compensated** | **If ported/compensated** |

| **Slide Lightening Cuts** | Not allowed behind ejection port | Not allowed behind ejection port |
| **Frame mounted optics** | no | no |
| **Gas Pedals** | Allowed given a maximum added width of 3/8” (0.375”). Folding/deployable thumb rests will be measured in deployed configuration. | Allowed given a maximum added width of 3/8” (0.375”). Folding/deployable thumb rests will be measured in deployed configuration. |
| **Flashlights/lasers** | allowed | allowed |
| **Magwells** | maximum width of 1.625in | maximum width of 1.625in |
| **Concealment requirement** | Must be shot from concealment ([Section 2.10](<02_Competitor Equipment.md#id-2.10-concealment>)) | Must be shot from concealment ([Section 2.10](<02_Competitor Equipment.md#id-2.10-concealment>)) |
| **Handgun requirement** | Must be a handgun per [Section 2.4.1](<02_Competitor Equipment.md#id-2.4.1-handgun>) | Must be a handgun per [Section 2.4.1](<02_Competitor Equipment.md#id-2.4.1-handgun>) |
| **Other restrictions** | no | no |

## G.2 Rifle Divisions Modifications

The following rules apply to all Airsoft rifles used in PCSL matches, modifying their respective sections in [Appendix B_Rifle Divisions](Appendix%20B_Rifle%20Divisions.md). Criteria regarding Minimum Caliber, Maximum Caliber, Maximum Bullet Velocity, and Minimum Power Factor are completely removed and superseded by the kinetic energy limits defined in [Section F.4.1](<Appendix F_PCSL Airsoft Modifications.md#id-f.4.1-chronograph-and-kinetic-energy-limits>).

### G.2.1 Competition (COMP)

Modifying [Section B.1.1](<Appendix B_Rifle Divisions.md#b.1.1-competition-comp>):

| **Criteria** | **Specification** |
| --- | --- |
| **PCC allowed** | Pistol Caliber Carbines as defined in [Section A.1.3](<Appendix A_Pistol Divisions.md#a.1.3-pistol-caliber-carbine-pcc>) |
| **Optics** | no restrictions |
| **Suppressors** | allowed |
| **Support devices** | Bipods, bags, and related support devices are allowed in PCSL Rifle or 3-Gun matches in Competition division only, but not in PCSL 2-Gun matches. |
| **Tripods** | Tripods are never allowed outside of PCSL 3-Gun Open division |
| **Rifle requirement** | Must be a rifle per [Section 2.4.2](<02_Competitor Equipment.md#id-2.4.2-rifle>) |
| **Other restrictions** | no |

### G.2.2 Practical (PRAC)

Modifying [Section B.1.2](<Appendix B_Rifle Divisions.md#b.1.2-practical-prac>):

| **Criteria** | **Specification** |
| --- | --- |
| **PCC allowed** | no |
| **Optics** | no restrictions |
| **Maximum rounds loaded in magazines at start signal** | 30 |
| **High-capacity magazines** | Magazines that are capable of holding more than 30 rounds (including drums) are allowed provided that they are only loaded to 30 rounds at the start of the stage |
| **Coupled magazines** | Coupled magazines (side by side) are prohibited |
| **Magwells** | Magwells up to 2.000” outer width are allowed |
| **Suppressors** | allowed |
| **Muzzle brakes** | Allowed (due to lack of actual recoil mitigation in Airsoft platforms) |
| **Blast mitigation devices** | Allowed |
| **Bolt Carrier Groups** | Lightened or Reduced Mass BCGs are prohibited. The specific acceptable weight variance from the OEM BCG mass shall be strictly determined by the Match Director (MD) on a per-match basis. |
| **Support devices** | Tripods, bipods, bags, and related support devices are prohibited |
| **Rifle requirement** | Must be a rifle per [Section 2.4.2](<02_Competitor Equipment.md#id-2.4.2-rifle>) |
| **Other restrictions** | no |
